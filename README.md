# Tebak Angka

Game tebak angka sederhana yang berjalan di browser, dibuat dengan HTML, CSS, dan JavaScript.

🔗 **Main di sini:** https://tfandena1602-del.github.io/tebak-angka/

## Cara bermain
1. Komputer memilih angka acak dari 1 sampai 100.
2. Kamu punya **7 kesempatan** untuk menebak.
3. Setiap tebakan mendapat petunjuk: terlalu kecil atau terlalu besar.
4. Ada juga petunjuk jarak: **Panas sekali** (selisih ≤ 5), **Hangat** (≤ 15), atau **Dingin**.
5. Tekan **Main lagi** untuk mengulang dengan angka baru.

## Fitur
- Angka rahasia acak setiap permainan
- Batas 7 percobaan dengan penghitung percobaan
- Petunjuk jarak panas / hangat / dingin
- Validasi input (hanya angka 1 sampai 100)

## Teknologi
HTML, CSS, JavaScript

## Yang dipelajari
- Variabel, kondisi `if / else if`, dan fungsi
- Mengambil dan mengubah isi elemen dengan DOM
- Angka acak dengan `Math.random()`
- Mengelola status permainan (`selesai`, `percobaan`)
